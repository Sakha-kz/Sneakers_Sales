# NorthX — запуск и управление магазином

**Создание администраторов, вход, выдача и отзыв доступа:** [отдельная пошаговая инструкция NORTHX-ADMINS.md](NORTHX-ADMINS.md).

Рабочая папка: `E:\Sneakers_Sales`. Нужен Node.js 22 или новее.

## Запуск на компьютере

В PowerShell:

```powershell
Set-Location E:\Sneakers_Sales
npm ci
npm run dev
```

Витрина: http://localhost:3000/ru. Панель владельца: http://localhost:3000/ru/admin.
Доступны также /kk и /en. Переключение языка есть в обеих частях сайта.

Без подключения Supabase можно посмотреть 3D. Вход в админку отключён, каталог показывает сообщение о недоступности. Тестовые товары в реальную витрину не подставляются.

## Подключение общей базы — один раз

1. Создайте проект Supabase.
2. В SQL Editor последовательно выполните `supabase/migrations/001_northx.sql` и `002_validate_catalog.sql`. Если первая миграция уже применена, повторять её не нужно.
3. В Auth отключите публичную регистрацию покупателей. В Auth → Users создайте пользователя владельца с email и надёжным паролем, подтвердите email. Скопируйте UUID этого пользователя.
4. В SQL Editor добавьте его в список администраторов:

```sql
insert into public.admin_access (user_id)
values ('UUID_ПОЛЬЗОВАТЕЛЯ_ИЗ_AUTH')
on conflict do nothing;
```

5. Скопируйте `.env.example` в `.env.local`. Укажите URL проекта в `NEXT_PUBLIC_SUPABASE_URL` и публичный anon/publishable key в `NEXT_PUBLIC_SUPABASE_ANON_KEY`.
6. Перезапустите сервер. При публикации эти же переменные нужно задать до сборки.
7. Войдите на /ru/admin, сохраните настоящий номер WhatsApp и адрес, добавьте товары.

Секретный service-role key для сайта не нужен. Не помещайте его в переменные NEXT_PUBLIC.

## Что умеет редактор

- Названия и описания на RU, KK, EN; цена в тенге, категория.
- До 8 фотографий, превью до сохранения, выбор обложки и удаление снимков из карточки.
- Выбор файлов, перетаскивание и фото с камеры телефона.
- JPEG, PNG, WebP до 5 МБ на снимок.
- Размеры 36–46: отдельные кнопки, выбрать все, снять выбор.
- Наличие, редактирование, удаление с подтверждением.
- Уведомления об успехе и ошибках; при ошибке загрузки уже отправленные снимки повторно не загружаются.
- Адрес на трёх языках и номер WhatsApp для всех заказов.

Клиенты получают изменения через Supabase Realtime, с резервной проверкой каждые 15 секунд при открытой вкладке. Корзина остаётся в браузере; перед переходом в WhatsApp проверяются текущее наличие и размеры. Клиентские аккаунты и персональные данные покупателей сайт не сохраняет.

Фото в Storage после удаления товара не стираются автоматически, чтобы не уничтожить используемый в другом товаре снимок. Неиспользуемые файлы можно удалить в Supabase Storage после проверки.

## Данные и защита

| Объект | Поля / назначение |
| --- | --- |
| products | id, title RU/KK/EN, description RU/KK/EN, price, images, sizes, category, isStock, isFeatured, color, created_at |
| settings | одна запись id=1, whatsapp_number, store_address RU/KK/EN |
| admin_access | UUID разрешённых администраторов из Auth |
| product-images | общедоступные фото; запись только администраторам |

Zod проверяет формы. Ограничения PostgreSQL проверяют данные при прямом обращении к API. RLS проверяет права на изменение товаров, настроек и файлов. Администратор не может выдать себе права через клиентское приложение. UI не является границей безопасности.

Основа: [Supabase RLS](https://supabase.com/docs/guides/database/postgres/row-level-security), [Storage access control](https://supabase.com/docs/guides/storage/security/access-control).

## Проверки

```powershell
npm run typecheck
npm run lint
npm run build
npm audit
npm run test:e2e
npm run test:rls
```

Тест RLS запускает обе миграции на PostgreSQL в памяти (PGlite) и проверяет права анонимного клиента, обычного пользователя и администратора, а также ограничения данных. Это не проверяет настройки настоящего Supabase.

Браузерные тесты используют изолированные ответы API, вымышленные аккаунты и порт 3100. Они не отправляют запросы в настоящую базу. На Windows используется установленный Chrome; на другой системе выполните `npx playwright install chromium`. Если порт 3100 занят другим проектом, освободите его перед тестом. Скриншоты сохраняются в `artifacts`.

После подключения реального Supabase отдельно проверьте:
- анонимный клиент и пользователь без записи admin_access не могут добавлять, менять и удалять товары/настройки/файлы;
- администратор может выполнить все эти операции;
- сохранённый на телефоне товар появляется на другом устройстве;
- заказ открывает WhatsApp магазина с нужными размером, количеством и суммой.

Эти проверки требуют настоящего проекта Supabase; браузерные заглушки их не заменяют.

## Производственная сборка

```powershell
npm run build
npm run start
```

Обновлено до Next.js 15, React 19 и совместимых версий React Three Fiber/Drei. Проверка TypeScript во время сборки включена. ESLint запускается отдельной командой. Значок и меню Next.js Dev Tools отключены через `devIndicators: false`; на опубликованной сборке их также нет. После изменения этой настройки локальный сервер нужно перезапустить.

Сцена использует общий масштаб коробки и обуви, крышка открывается до подъёма модели. Коробка белая, с деталями и мягкой подсветкой основания. После распаковки кроссовок делает полный оборот на 360° при прокрутке; при прокрутке назад движение обращается. Фон графитовый. Материалы матовые, цветовые варианты берутся из GLB. На телефонах отключены тяжёлые эффекты, DPR ограничен 1.5. Вне экрана и в скрытой вкладке WebGL останавливается; Lenis работает только при прокрутке. При «уменьшении движения» в настройках устройства 3D пропускается.

3D-модель: © 2021 Shopify, Materials Variants Shoe, CC BY 4.0. Подробности: `public/models/ATTRIBUTION.txt`. Это демонстрационная модель витрины; сведения о продаваемых парах задаются в карточках товаров.
Выбор расцветки расположен вертикально справа и доступен на протяжении всей 3D-сцены. Выбор сохраняется в браузере между прокрутками, перезагрузками и сменой языка; меняется только при нажатии другой расцветки. При переходе к каталогу панель скрывается вместе со сценой. Масштаб учитывает ширину и высоту экрана, место под панель и текст.
